# Berlin Star — React version

تم تقسيم المشروع إلى Components قابلة لإعادة الاستخدام:

- TopBar
- Navbar
- Hero
- SearchBox
- Features
- Trips
- CarsBanner
- Footer
- BookingModal
- Toast

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يظهره Vite.

## ملاحظة الصور
ضع صور المشروع الأصلية داخل مجلد `public/` بالأسماء الموجودة في `src/data/trips.js` واسم `ico.png`.
